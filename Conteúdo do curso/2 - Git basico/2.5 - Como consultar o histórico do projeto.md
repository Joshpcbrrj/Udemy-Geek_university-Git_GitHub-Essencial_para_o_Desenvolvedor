# 2.5 · Como consultar o histórico do projeto

> **Em uma frase:** o `git log` mostra a lista de todos os commits do projeto, do mais recente para o mais antigo, e tem várias opções para filtrar o que você quer ver.

## 📜 O comando `git log`

```bash
git log
```

Ele mostra, para cada commit:

- o **hash** (identificador único);
- o **autor** (nome e e-mail);
- a **data**;
- a **mensagem** do commit.

### Exemplo de saída

```text
commit c12a3b4d56e7890123456789abcdef0123456789 (HEAD -> main)
Author: John Doe <johndoe@example.com>
Date:   Sun Jul 2 15:30:00 2023 +0200

    Adiciona nova funcionalidade

commit a1b2c3d4e5f67890123456789abcdef012345678
Author: Jane Smith <janesmith@example.com>
Date:   Sat Jul 1 09:45:00 2023 +0200

    Atualiza documentação

commit 1234567890abcdef0123456789abcdef01234567
Author: John Doe <johndoe@example.com>
Date:   Fri Jun 30 16:20:00 2023 +0200

    Commit inicial
```

> [!TIP]
> Repare no `(HEAD -> main)` do primeiro commit. Ele indica **onde você está agora**: o `HEAD` é um ponteiro para o commit atual, e `main` é a branch em que você está.

> [!NOTE]
> Se o histórico for grande, o Git abre a lista em um "paginador". Use as **setas** ou **espaço** para rolar e aperte **`q`** para sair.

## 🔍 Variações úteis do `git log`

```bash
# Versão resumida: uma linha por commit (hash curto + mensagem)
git log --oneline

# Só os 2 últimos commits
git log -2

# Combinando opções: os 5 últimos, em uma linha cada
git log --oneline -5

# Commits de um autor específico
git log --author="John Doe"

# Commits dos últimos 2 dias
git log --since="2 days ago"

# Commits antes de uma data
git log --before="2023-06-05"

# Commits depois de uma data
git log --after="2023-02-05"

# Commits cuja mensagem contém uma palavra
git log --grep="bugfix"

# Mostra quais arquivos cada commit alterou (e quantas linhas)
git log --stat

# Mostra o conteúdo exato das alterações (o "diff") de cada commit
git log -p

# Desenha o histórico como um gráfico, com todas as branches
git log --graph --oneline --decorate --all
```

### Tabela de referência rápida

| Opção | O que faz |
| --- | --- |
| `--oneline` | Uma linha por commit |
| `-N` (ex.: `-3`) | Mostra só os N últimos commits |
| `--author="nome"` | Filtra por autor |
| `--since` / `--after` | Commits a partir de uma data |
| `--until` / `--before` | Commits até uma data |
| `--grep="texto"` | Filtra pela mensagem do commit |
| `--stat` | Mostra arquivos alterados e quantidade de linhas |
| `-p` | Mostra as alterações linha a linha |
| `--graph --all` | Desenha o gráfico de branches |

## 📚 Quer saber mais?

O próprio Git tem um manual completo de cada comando:

```bash
git help log
```

## 📌 Resumindo

- `git log` lista os commits do mais novo para o mais antigo.
- `git log --oneline` é a forma mais prática de ter uma visão geral.
- Dá para filtrar por quantidade (`-N`), autor, data, mensagem e muito mais.
- `git log --graph --oneline --all` mostra o "mapa" das branches.
